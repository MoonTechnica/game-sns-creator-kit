# 出荷前のチェック（出力の前に 1 回）

体験の細かな数値（文字・コントラスト・点滅）は `$game-ux` §9 のチェックにある。ここはゲームとして成立しているかだけを見る。

- [ ] `design/brief.md` の「一文で」と実際の遊びが一致している
- [ ] 「作らないもの」を作っていない。ジャンルの下限（genres-minimum.md）はそろっている
- [ ] 最初の画面から 1 回の操作で遊び始められ、最初にすることが画面に出ている
- [ ] 入力への反応が同じフレームで返り、押した感（見た目 + 音）がある
- [ ] プレイヤーに有利なごまかし（猶予・当たり判定）が `tuning.ts` にある
- [ ] 勝ち・負けが必ず起きる。負けた理由が画面で分かる
- [ ] 行き止まり（手が無い・動けない・出られない）が無い。詰んだら戻す
- [ ] リザルトから操作 1 回・1 秒以内に再開できる
- [ ] ポーズと設定（効果音 / BGM / 揺れ）がある
- [ ] `design/playtest.md` の必須項目が全部 ✓（`$game-playtest`）
- [ ] 段階 8 以降で機能を足していない
- [ ] 掲載情報（名前・説明・遊び方・カバー）が実装と一致している（`$game-listing`）
